# IT Help Desk & Ticketing Management System

## Project Description
A web-based IT Help Desk and Ticketing Management System designed to help employees submit technical support requests and allow IT staff to manage, assign, and resolve tickets.

## Project Objectives
- Manage support tickets
- Allow employees to submit requests
- Allow technicians to handle tickets
- Provide administrator management features
- Store and organize support information

## Features
- User authentication
- Ticket creation and tracking
- Ticket assignment
- Status management
- Comments and attachments
- Admin dashboard
